# Phase 1 checklist

## A. Brand
- [ ] Copy the official logo file into `01-Brand-Assets/` (do not redraw or alter it).
- [ ] Confirm approved colours/fonts if already defined.
- [ ] Confirm public contact details.
- [ ] Decide whether a founder portrait or behind-the-scenes image is suitable and comfortable to publish.

## B. Software
- [ ] List all relevant repositories from https://github.com/thunderlight247/
- [ ] Fill project purpose, role/contribution, status, tech stack, evidence, and permission fields in `PROJECT_INVENTORY.csv`.
- [ ] Capture desktop and mobile screenshots for promising projects.
- [ ] Check public repositories for secrets or client data before linking.
- [ ] Confirm whether `baduwa.vercel.app` is the same business/project as Beduwa Naturals.

## C. Media
- [ ] Locate original photographs, videos, edits, and graphic designs on the computer.
- [ ] Record filenames and file paths before moving anything.
- [ ] Select an initial 10–20 photographs if enough suitable material exists.
- [ ] Select 2–5 video samples if available.
- [ ] Select a few graphic-design examples.
- [ ] Confirm whether client and event images can be shown publicly.
- [ ] Keep unedited originals backed up.

## D. Privacy and permission
- [ ] Record permission status for each client asset.
- [ ] Do not publish restricted work or identifiable people without appropriate permission.
- [ ] Remove private information and confidential materials.
- [ ] Keep private credentials and `.env` files out of the portfolio folder/repository.

## E. Shortlist
- [ ] Choose the strongest 3 media projects.
- [ ] Choose the strongest 2 software projects for initial case studies.
- [ ] Mark all work accurately: live, completed, prototype, in development, or paused.
- [ ] Complete the progress log.

## Phase 1 exit criteria
We are ready for Phase 2 when the inventory is filled enough to select projects, the best examples are identified, permission risks are noted, and the intended Software/Media visitor split is confirmed.
